# Group-17-B-AI-LLM-chatbot-for-UTS-FEIT

1. Install Ollama - Download from ollama.com. Run ollama serve to start the server.
2. Pull a model - Run ollama pull llama3.1 (or mistral, phi3 — pick based on your hardware). Llama 3.1 8B is a good balance of quality and speed.
3. Test it - Run `ollama run llama3.1` in terminal to confirm it works.

Data is where the UTS FEIT PDFS go 

### How to run streamlit 
`streamlit run app.py`
